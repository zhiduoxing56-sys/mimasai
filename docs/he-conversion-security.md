# 同态转换完整视图与本轮保护

## 结论及范围

旧 `legacy_ciphertext` 转换继续保留为**正确性诊断，安全阻塞**。本轮新增 `private_decryption`：保留真实 SEAL 求值、常数项提取和打包，但不向私钥持有者发送求值密文；双方通过可信离线 Beaver 环乘法和秘密布尔舍入计算 BFV 解密函数，结果仍为共享。本构造是交互式私有输入解密的工程适配，**不是原论文随机化 BFV 或低交互密文净化的实现**。两条路径必须显式选择，缺少选择时报错。

安全结论依赖半诚实双方、有效密钥与输入、可信且不串谋的离线方、既有算术/布尔协议的安全性和组合。未给出机器核验安全证明；输出对齐测试不是安全证明。普通 BFV 的电路隐私缺口仍存在，只是在新路径中不把导致该缺口的对象交给接收者。

## 旧路径的完整视图

S0 持 pk0、gk0、sk1，自身特征份额 T0、pk0 下原始邻域密文、自身全部求值/提取/打包密文、随机全系数掩码 r0、对方 pk1 下的掩码求值密文，以及解密所得多项式；S1 对称。公开部分包括参数、节点/列顺序、形状、操作计划、会话和随机材料标识。评估密钥是十三个 Galois 密钥，无需本次 ct×pt 的重线性化密钥。生成方 V/密钥设置方生成两组独立密钥，交叉分配私钥，不在服务器目录留下自身计算密钥的私钥。

持 sk1 的 S0 能从收到的密文计算完整 phase=c0+c1*sk1，解码后还能计算相对于明文嵌入的误差，不止获得均匀掩码后的最终明文。普通 sub_plain 不改变 c1；因此扩大明文掩码不能消除此视图。若 S0 还获得 pk1 下原始图密文，可直接解码相应图权重；当前合法服务器目录没有对方原始图密文，但不能声称在允许该额外输入的模型下图仍秘密。同方 Galois 评估密钥也可从其私钥重新生成，不能把隐藏评估密钥作为保护手段。

需要保护对方特征份额、模型/中间状态以及未授权图数据。模拟器允许知道被腐化方自身输入份额、交叉私钥及其计算公钥/评估材料、自己持有的原始密文、全部公开结构、约定的批次有效/停止标志和输出份额；不允许得到对方份额、完整模型、误差或完整输出。若另行把可用交叉私钥解密的原始密文列为合法输入，相应解码值必须计入允许视图，不能同时承诺隐藏它。

2. Gaussian noise flooding/净化：需公开可证明的求值误差上界 B、与秘密输入无关的分布、统计距离参数及解码容量。仅实测 noise budget 不足以设定 B。当前未审计完整 Galois key-switch 与特殊投影的误差放大，未实现有证明的 flooding，也未声称 tc128 等于统计电路隐私。
3. [Gazelle, USENIX Security 2018](https://www.usenix.org/system/files/conference/usenixsecurity18/sec18-juvekar.pdf)，Appendix B（PDF 第18页）：提出交互解密以免暴露解密误差。本文选择更直接的私有输入函数实现：连 c1 都不公开，通过环 Beaver 计算 c1*sk，再通过秘密电路精确舍入。不是复用 Gazelle 的优化 GC 或近似除法代码。无第三方新增代码许可依赖；SEAL 4.1.0 仍 MIT。

## 新路径与代数

每个贡献密文有二项 c0,c1；Q 是 SEAL first_context 的三个 data 素数乘积（约164位），特殊 key-switch 素数不进入解密 Q；t=2^32，N=8192。服务器 j 私有持 c0,c1，服务器 1−j 私有持 sk_j 系数。仅各自加载这些本地输入，绝不加载对方目录。

离线方只读取公开 parameters，在 R_Q=Z_Q[X]/(X^N+1) 中均匀生成 A,B，计算 C=A*B；三个多项式各自独立加性拆分。逐个随机 material_id 在所有批次间持久预留，先消耗再打开。在线打开 D=c1−A、E=sk−B，整环掩码均匀且独立；输出份额 C_i+D B_i+E A_i+[i=0]DE。c0 只加入其持有方。RNS 系数乘法用 SEAL NTT，CRT 仅对**自身相位份额**进行，任何完整相位均不恢复。Beaver 代数在此有限交换环成立，无需它是域。

对目标系数，双方持 u0,u1 ∈[0,Q)，u=(u0+u1) mod Q。令 h_i=floor(t*u_i/Q)，r_i=t*u_i mod Q。秘密计算两个位

b1=[r0+r1 ≥ Q−floor(Q/2)]，b2=[r0+r1 ≥ 2Q−floor(Q/2)]。

输出 h_i+b1_i+b2_i mod t，其和等于 floor((t*u+floor(Q/2))/Q) mod t。原因是两份余数之和小于2Q，舍入修正为0、1或2；相位绕 Q 只使结果减 t，输出环中消失。Q 奇数、t 为2的幂，无半值歧义。余数加法、比较和 B2A 全部秘密，无低位或符号打开。这是 BFV 解密舍入，不是模型的 f7 向下截断；两方贡献合成后仍调用已有 exact_truncate，顺序不变。

两贡献解密份额加上各自原先全 N 系数均匀掩码，得到聚合共享。未使用系数也生成掩码；新路径不传输其原始相位或解码值。公开只有结构、随机 ID、一次性 Beaver 掩码打开消息和既有范围批次标志。所有秘密相关循环长度由公开 N/列数/Q 位数固定。

## 模拟与正确性边界

标准可信预处理模型中，被腐化方本地 triple 份额和打开 D,E 可按均匀环元素模拟；在线消息的秘密相关性由未腐化方未知的独立 A/B 吸收。布尔比较/转换继承既有可信离线协议的组合安全；将原始 c0,c1 和 sk 作为该安全函数的私有输入，接收者既看不到对方求值密文，也没有完整相位及误差。自身求值过程由自己的原始密文及份额决定，模拟器可重放。此论证不以 BFV circuit privacy 为前提；对隐藏图的保证另依赖各服务器没有相应私钥的 IND-CPA 输入加密与密钥设置假设。跨钥合法视图不可擅自扩大。

精确函数验证包括小环全部相位份额组合、32位实际 Q 边界随机及直接 phase 对 SEAL 解码。BFV 解码出的明文是否等于预期聚合仍依赖 HE 正确性噪声条件；本轮只验收已测小图及测试端范围检查夹具，未以实测噪声推导所有任意规模的通用误差上界。SEAL CBD 构建噪声系数有界，但提取/切换的完整解析上界尚待独立审计。双方若输入恶意密文/错误份额，不在本轮半诚实保证内。

全系数均匀掩码仍存在，但安全保护来自私有解密函数，不能独立把掩码或 Enc(0) 当成电路隐私证明。本机 IPC 没有跨机认证加密、执行目录只有应用级视图检查而无 OS 用户隔离；主机管理员可读所有目录。离线方不能看到在线消息，也不与任何在线服务器串谋。该假设不决定未来训练辅助方是否合并。

实现没有常数时间保证：Python大整数、文件系统和原生调用可能有计时/资源侧信道。本轮安全论证针对规定消息与半诚实视图，未覆盖本地主机或微架构侧信道。

## 真实数据轮的补充边界

已在Cora诱导16节点的实际共享训练模型上接通本私有输入解密路线。训练的乘积/部分和由点积前秘密L1及操作数范围守卫保障；HE聚合使用合法归一化P的公开系数上界及已秘密检查的状态界，仍依赖拥有者正确准备P，没有加密P范围证明或私人归一化。P同一源矩阵在f12/f7分别准备，不把拥有者重编码当作秘密转换。测试仍不能替代提取/切换通用噪声上界审计。

本机运行通道是socketpair IPC，非跨机认证部署。两密钥的总Galois评估材料为41034462字节（不是每方该大小），离线文件分发不计入线上IPC发送量。公开Cora及可复现初始权重使该基准本身不代表未知私人模型/数据部署；秘密运算路径与安全论证是对相应有效私有输入的条件保证。
