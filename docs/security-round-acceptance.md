## 故障与回归

秘密 BFV 舍入检查1853个输入份额对，包括小环全穷举及32位实际Q边界/随机。断连（Beaver打开之后）、公开上下文不一致、非规范RNS份额三项明确失败；原批次重启全部 BATCH_ALREADY_RESERVED，换批次标签但保留旧环材料 ID 全部 RING_MATERIAL_REUSE。材料在连线前全部预留，因此早期失败的未消费项也不可重新使用。

阶段二第一轮与第二轮回归已运行通过。早期新验证端 oracle 路径错误曾失败；修复验证文件路径并用新材料复跑，未用明文替代在线路径。失败说明留在 results/security-round/failures.json。源码审阅与可重现入口见 [审阅说明](source-review.md)、[工程基线](reproducibility.md)。

## 训练限制的独立证据

60组固定合成初始化覆盖隐藏权重尺度0、0.25、0.5、1、2、3及输出权重对比；57组满足当前损失定义域，3组目标概率低于1/4，未发现该网格内前向溢出/范围拒绝。对失败样例实际运行秘密损失，整批 LOSS_PROBABILITY_DOMAIN 拒绝，重启拒绝重用。失败位置/概率只在独立验证端已知合成样例中记录，不是服务器公开信息。

范围归约对数候选仅完成明文定点参考：对全部1…4096正概率单位，秘密规范化候选 u=q*2^k∈[S/2,S]，degree8 Taylor，k≤12，最大绝对误差0.0019039561。需要秘密最高位/条件移位及正概率验证；概率量化为0仍须拒绝或另行改变有明确依据的语义。未接入秘密训练，未公开目标概率绕过限制。

既有三轮共享训练→真实份额发布→两层共享推理闭环保留。训练仍限已验证f12约束、当前有界近似概率、目标概率≥1/4、公开训练掩码与当前节点结构；梯度采用近似标准p−y而非对Taylor概率/损失求导。安全秘密图归一化、作者原辅助索引协议、跨环转换、通用HE解析误差界、认证/MAC/主动安全仍未完成。本轮没有扩大串谋假设或恢复模型给拥有者。
