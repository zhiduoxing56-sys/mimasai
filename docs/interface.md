# 训练到推理接口与数值规则

唯一可执行配置仍为 `config/phase0.json`（保留阶段零文件名）。阶段一由用户明确选择下述第一版参考语义。模型文件中的 binding 是配置的不可变快照，用于校验，不是另一套配置入口。源码为 `src/reference.py`；所有训练、模型明文保存和共享恢复均属于独立参考测试。

## 图与模型语义

输入为无向、非负、有限权重边三元组 `[u,v,weight]`，端点为 0 到 N−1 的整数，输入自环直接报错。每条记录代表一条无向边；包括反向重复记录在内的重复边按权重相加，不自动推断两条记录是同一边。零权边不影响度。预处理恰好加入一次单位自环，得到 Ahat，`D[i]=sum_j Ahat[i,j]`，`P[i,j]=Ahat[i,j]/sqrt(D[i]D[j])` 表示 j 到 i 的消息。孤立点 P 的对角为 1。特征不另做归一化。node_order 保存全局标识到矩阵行号的一一映射。

两层形状 F→H→C。本例为 2→3→2。只有 W0、W1 训练；偏置固定为公开零，没有偏置参数数组。前向为 `T0=XW0; Z0=P T0; H1=ReLU(Z0); T1=H1 W1; Z1=P T1; Y=softmax(Z1)`。ReLU 零点导数取 0，末层没有 ReLU。训练和推理读取同一个 P；同态编码包括归一化后的对角权重，不能额外补单位自环。

比赛 3.2.2 与算法3.1的隐藏层激活/输出概率安排是文档明确规定；固定零偏置、无向非负输入、拒绝原始自环、重复权重求和及前置变换是本轮用户确定的实现选择。保留材料差异：比赛3.4包含偏置接口；HyGNN III-A为有向图，IV-A/IV-B的单位自环不能直接套到归一化矩阵，V-B Step5–7文字包含末层激活。未修改原始材料。

训练掩码是严格布尔 `[N]`，至少一个 True；标签是 `[N]` 类别整数。损失为训练节点平均交叉熵，掩码只去除对应损失及输出误差项，未标记节点仍参与全图传播与梯度传递。浮点损失采用 log-sum-exp，概率采用减行最大值后的 softmax。反向按上述前置变换链式求导，缓存 P、T0、Z0、H1、T1、Z1、Y、输出误差、两层梯度。初始和训练后缓存保存在 results/stage1/。

训练本轮固定160次梯度下降。独立收敛参考函数接收非负 `abs(L_current-L_previous)` 序列；`diff<=threshold`（包含等号）才累计，失败清零，连续 window 次停止；至多 max_iterations 次。相同次触发窗口与上限时窗口优先。比赛式4.14的标志极性差异保留，密态比较及停止泄露尚未实现。

## 32位环、7位小数与执行顺序

推理参考环为 Z/(2^32)，尺度 S=128。浮点编码 `round(x*S)` 使用 nearest ties-to-even；编码后检查有符号范围 `[-2^31,2^31)` 再取模。有符号解释为值小于2^31时原值，否则减2^32。乘积、整个点积累加尺度为 S²；每个矩阵点积结束仅一次 `floor(acc/S)` 恢复 S，包括负数向负无穷取整。不是逐个乘积先截断。

使用 Python 宽整数分别检查每个真实乘积和每个部分累加，越出有符号32位范围立即 OverflowError；同步环计算与宽整数结果核对，不允许把回绕当正常输出。每个矩阵乘法保存原始累加与最大中间值。前置变换依次在 XW0、P T0、H1 W1、P T1 后截断。对照路径在 PX、(PX)W0、P H1、(P H1)W1 后截断。两路径只比较相同语义节点状态，不要求逐位一致。

概率先用80位十进制精度 Decimal.exp 作明文对照，不是多项式近似，也不是安全概率协议。浮点输入转换为其 `str(float)` 十进制表示，不能解释成精确恢复原实数。本轮不实现定点训练；32/7不指定为全部密态训练精度，浮点参数一次量化仅用于推理参考。

### 消息与失败处理

本机使用AF_UNIX socketpair，验证端分发文件描述符后关闭它们；两个服务器直接收发。协议帧为网络序4字节body长度、4字节header长度、UTF-8 JSON header、二进制payload。header字段：version、session、sequence、operation、type、shape、dtype、payload_length、material_span。u32载荷每值4字节小端，bit载荷每位1字节且必须0/1；长度含前缀计入通信量。shape乘积等于元素数，元数据类型/值严格核对，不接受布尔数替代整数字段。sequence每次双向交换递增，operation为公开操作编号；material_span为种类、起始编号、数量。握手核对公开调度与批次一致。

最大帧4MiB，socket超时5秒。顺序、会话、调度、形状、长度或载荷位错误立即异常终止；对方观察断连/超时，不发送包含秘密的异常详情。日志只有状态、公共编号、字节、轮数和消耗数量。每次成功双向交换计一轮；两个方向依次收发，不能把此定义混为一个单向网络消息或跨机器往返测量。算术加减及公开标量乘无在线轮数；乘法批处理1轮；32位截断32轮；截断矩阵乘33轮。握手另计1轮。

### 一次性材料与持久状态

算术三元组为 `[a],[b],[ab]`，布尔三元组为 XOR份额 `(a,b,a AND b)`，daBit为同一个随机位的布尔份额和Z/(2^n)加性份额。离线随机源为 secrets/操作系统随机，不使用固定种子。材料文件只保存本角色份额，权限0600、角色目录0700。

启动在线进程时，在 `state/mpc/S0-ledger.sqlite` 或S1账本内先事务保留完整batch，再读取输入、建立通信。SQLite同步级别FULL；每个取用编号在消息发送前持久记录。任何完成、断连、超时或强制终止后的batch都不可再次启动，即使部分材料未用完也烧毁；本轮不支持会话恢复或余料回收。进程崩溃留下reserved状态也一律拒绝，不能reset cursor后继续。重启、复制材料文件、改材料路径均不能绕过同一batch主键。账本不是构建产物，禁止删除、回滚或恢复旧备份；本轮假定状态存储与运行方按协议诚实，未提供抵抗恶意宿主回滚的外部单调计数器。清理build中的测试秘密文件不应清理state账本。

### 算术与矩阵

加减按份额本地取模，公开标量直接乘每份额。乘法取新三元组，打开 `d=x-a`、`e=y-b`（只打开随机掩码差）。输出 `z_i=c_i+d*b_i+e*a_i+I(i=0)*d*e mod 2^n`，公共交叉项仅S0加入。两服务器都只知道各自a_i/b_i，不知完整掩码；可信方若看到这些打开值就可推回输入，因此明确禁止其在线观察或串谋。

矩阵乘将每个乘积展开并使用独立三元组批处理，每个点积在环中累加全部乘积，然后只调用一次精确截断；不逐个乘积截断。验证端使用阶段一Fixed宽整数乘积/部分和检查夹具并产生期望值。服务器只有单份额，未提供明文式溢出检查；共享范围校验仍未实现。单独的环加减与截断允许份额进位和模环回绕；点积作为数值运算的正确性另以测试夹具无真实溢出为前提。

### 精确截断构造与代数推导

本轮目标对任意n位环元素成立：`Trunc_f(x)=floor(signed_n(x)/2^f) mod 2^n`，0<f<n；生产目标n=32/f=7。范围是完整 `[-2^(n-1),2^(n-1)-1]`，输出仍在同一个n位环，既无概率舍入也无一单位容差。

1. **算术转布尔。** 各方只分解自身加性份额的本地位。为两个私有加数分别构造布尔输入：S0持a位且其b份额为0，S1持b位且其a份额为0。不公开任何位。逐位秘密加法：`p=a XOR b; sum=p XOR carry; carry'=(a AND b) XOR (p AND carry)`。最后舍弃第n位进位，得到 `(x0+x1) mod 2^n` 的布尔共享。两个AND项在真实布尔值上不可能同时为1，因此XOR等于OR。每个低位2个新鲜布尔三元组，最后符号位不再计算进位，共2(n−1)个/元素，按位批处理n−1轮。AND使用同样的Beaver掩码公式（加法为XOR，乘法为AND，公共项仅S0）。
2. **符号扩展右移。** 对已经共享的完整和，仅连线保留位f..n−1。令m=n−f，结果有符号整数等于 `sum_{j=0}^{m-2} 2^j*b_{f+j} - 2^(m-1)*b_{n-1}`。负符号权重等价于在原n位输出环填充高位1，且精确对应负无穷取整。这里不是把两份算术输入各自右移。
3. **布尔转算术。** 对每个保留位b取独立daBit `(r_B,r_A)`，仅打开 `c=b XOR r_B`。c=0时输出 `[r]_A`，c=1时输出 `[1-r]_A`（公共1只由S0加入）。故份额和精确等于b；再按上面的公开权重相加得到n位加性输出。每元素n−f个daBits、1轮。符号位只转换一次，以负权重完成扩展，不重复使用其掩码。

正确性来自逐位加法与二补码恒等式；打开的AND掩码及daBit掩码都被独立新鲜随机量覆盖，不直接打开符号、低位、完整输入或中间值。本实现组合公开协议原语，可信离线方替代论文的OT/恶意一致性生成；不声称复现ABY/MP-SPDZ后端或继承其完整安全证明。完整推导、来源和适用假设见 dependencies.md、trust.md。常规Python实现未进行常数时间或侧信道审计。

## 阶段二第二轮：激活、范围及隐藏层接口（2026-10-03）

以下更新替代前文“共享缩位范围校验未实现”这一局部状态；训练宽整数溢出、跨环转换范围与完整训练范围保证仍未实现。

`sign(x)` 复用完整环 A2B，在秘密状态取 bit31，再用独立 daBit B2A 得到算术共享负号位。`select(x,b)` 使用一次 Beaver 乘法，b 为无小数尺度的0/1，结果保留 x 的尺度128，不做截断。`relu(x)` 取 b=1−sign(x)，公共1只加入S0份额；零输出零。这是布尔共享激活基准，不是FSS。

公开 k∈[1,32] 的有效区间为 [-2^(k−1),2^(k−1))。对 j=k,…,31，计算秘密位 e_j=1⊕bit_j⊕bit_(k−1)；全部相等当且仅当32位有符号值等于其k位符号扩展。负端包含、正端排除。将全批所有 e_j 用固定形状平衡AND树合并，只打开一个批次有效标志。k=32恒有效。失败不公开位置或数值，不发布本批输出，整批材料作废。这一个标志是新增泄露，不能证明此前宽整数乘积/部分和没有溢出：2^32+1回绕为1仍会通过k=10检查。

真实 FSS 后端为 `src/fss.py` 的前缀DPF比较，区别于论文优化DCF内核：每个阈值前缀生成一个真实DPF，包括秘密载荷为0的前缀；固定数量密钥不揭露阈值的1位位置。对公开 q 求值后异或，得到 [q<α] 的F2共享：唯一首个差异位贡献，端点为严格小于。输入群为m位无符号整数，输出群为F2；激活输出为Z/(2^32)。DPF按BGI Fig.1实现，128位种子由 secrets.token_bytes 生成，域分离SHAKE256扩展与输出转换。计算型安全依赖该PRG选择及独立DPF组合假设；没有外部密码审计或物理恒定时间保证。密钥不存阈值或函数真值表。此实现复杂度O(128m²)，不能声称复现论文O(128m)优化DCF。

离线每元素生成独立 rz∈Z/(2^32)、随机位 rb。令 a=(-rz) mod 2^k，α=a mod 2^(k−1)，rp=MSB_k(a)⊕1⊕rb，分别分发 rz 的加性份额、rp 的异或份额及各自比较密钥。在线先通过批次范围检查，再打开 δ=x+rz；令 q=2^(k−1)−1−(δ mod 2^(k−1))，双方求值比较份额。公共 MSB_k(δ) 仅进入S0份额，双方分别使用自己的 rp_i；σ_i=DCF_i(q)⊕rp_i⊕公共MSB份额。打开 h=σ0⊕σ1，它是非负选择位被rb掩码后的位，不是输入符号。

对h∈{0,1}，离线令 b=h⊕rb，分发随机仿射系数使 α0[h]+α1[h]=b、β0[h]+β1[h]=−b·rz。在线输出 α_i[h]δ+β_i[h]，份额之和为 bx，尺度不变。修正来源为阶段零对原算法失败的推导：公共符号只加一方、正确分发并使用rp_i；原文失败回归保留在 results/paper-activation.json。FSS核心2轮，每元素消费一份包含比较及选择的材料；调用前必须执行范围守卫。失败和掩码打开后断连均不得重用材料。

隐藏层测试接口保持节点顺序、公开形状与尺度：共享X×共享W0，整个点积后精确截断；共享P×共享T0，整个点积后精确截断；范围守卫；布尔或FSS激活。P包含归一化对角权重，不加额外自环。验证端独立恢复T0、Z0、H1测试输出，服务器只写自己的份额；这些中间状态接口仅为协议对照测试，不是正式模型发布接口。不是同态聚合或密态训练。

## 阶段三第一轮：真实同态聚合与交叉转换（2026-10-04）

本轮接口保持阶段一节点顺序、公开零偏置和前置变换顺序。五节点先用原共享矩阵乘得到T0=floor(XW0/128)，直接把同一进程内T0份额送入同态聚合；不恢复或重新拆分T0。十六/三十二节点采用已处于尺度128的合成T夹具，验证聚合及后续算子，未宣称其完整模型线性层已运行。

唯一配置新增执行次数选择 he_execution_degree=8192（必须来自既有he_degrees）及测试规模[5,16,32]；ring32、fraction7、系数模数[55,55,54,54]、tc128不变。C++从可信参数文件创建SEALContext并再次执行tc128检查；不用BatchEncoder，明文模数2^32保持系数编码。

设归一化传播P已量化，邻域A_i=Σ_j P_ij x^(-j)，包含归一化对角权重。j>0的位置为8192−j且系数为−P_ij mod2^32，j=0直接编码。特征每列B_c=Σ_j T_jc x^j，可由整个32位环的任意份额构成。各服务器分别计算ct(A_i)×B_c自己的份额。ExtractConst取LWE常数样本；反向嵌入保留c1、仅保留c0[0]，各系数模数q下乘8192逆元，再按8193,4097,…,3进行13次Galois trace消去非目标项。每个标量同态乘x^i并相加，每列得到一个含N个节点结果的密文，剩余系数按正确性测试为0。纯求值进程不加载私钥，提取/打包不解密、不重加密。全零本地列以公钥生成新鲜零密文进入同样的提取打包路径；不关闭透明密文检查，也不通过解密产生零。

离线密钥设置端生成独立(pk0,sk0,gk0)、(pk1,sk1,gk1)。S0只加载pk0/gk0/邻域ct0与sk1；S1只加载pk1/gk1/邻域ct1与sk0。本轮不需要重线性化键，因为在线只有密文×明文。Galois键由对应私钥的KeyGenerator生成后分发。测试端V保留两私钥副本，仅为独立系数/噪声验证，不构成正式发布方。

每服务器每列生成8192个独立均匀r_i系数，覆盖整份可解密多项式；每批3列共24576系数。发送C_i=Enc_i(A_i贡献−r_i)。S0解密收到的C1得到v1=A1贡献−r1，输出s0=r0+v1；S1输出s1=r1+v0，故s0+s1=A0贡献+A1贡献=P(T0) mod2^32。有效位置按行主序恢复形状[N,3]；未使用位置也全部掩码，不能假设提取残留永远为零而省略保护。转换是一轮双向密文交换。

原始聚合结果尺度128²。两贡献转换成一个共享环值以后，调用原完整32位精确floor截断，随后批次范围检查及布尔或真实前缀DPF-FSS激活；禁止分别截断贡献。两次截断分别位于XW0和P(T0)之后，不能合并。HyGNN V-B Step1先同态线性/聚合、Step2转换（PDF第8页），本轮前置共享线性/截断并改用共享T本地明文乘法，工程编排不同；不宣称通信成本与论文一致。

消息沿用MPC版本、会话、操作序号、长度、形状、材料span；新增byte载荷，内层版本privacy-gnn-he-convert-v1绑定计算角色、随机package_id、公钥指纹key_id、参数文件摘要、节点/列顺序、[N,3]与固定密文长度。标识不依赖明文模型权重。本地私钥文件完整性摘要只留在私人包，不放消息或日志。检查可信包/消息绑定不构成恶意发送方密文属于该密钥的密码证明。

每列一枚随机he_mask标识，沿用整批离线保留账本；在线take先耐久消费，再用secrets生成完整系数掩码。local/peer标识另有跨批次唯一约束。失败后整批作废、重启拒绝；即使搬入新批次也拒绝旧标识。普通统计只含数量和公开元数据。state/mpc不得删除或回滚。
