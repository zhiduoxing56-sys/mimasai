# 真实训练模型的受保护同态概率链路

## 运行入口及数据流

完整入口 `sh scripts/run_trained_he.sh`：检查唯一依赖锁、构建SEAL/桥、建立参考、运行三轮真实共享训练、共享发布和四条同模型推理/故障检查。不要求原始论文文件参与运行，不下载数据集。已有构建时可运行 `python3 verification/trained_he_chain.py --faults`（先有stage1结果）。默认重新训练和发布，只有调试标志 --reuse-current-publication 才读取本轮已完成发布；此标志不会复用预处理或账本。各运行均产生新会话/密钥/材料。

真实训练仍用已验收有效初始化与f12，初始权重是训练输入，**不是同态推理模型**。训练两进程的最终更新权重份额由 publication.py 逐角色传给发布进程；发布先在f12刷新，再秘密floor截断5位至f7、秘密范围检查、再次刷新，生成持久 additive-model-v1 文件。训练权重不在任何服务器恢复。

trained_he_chain.py 只将发布文件从S0复制到新S0、S1复制到新S1，独立验证端检查逐字节一致。推理worker的matmul.model/model_layer从自身持久模型文件加载W0/W1，禁止从输入y提供替代权重。图特征与传播共享输入也逐角色取自同一发布验证的授权输入文件，两条路径持同一模型及同一输入。复制输入/模型份额不会消耗旧预处理；新协议材料全部重新生成。文件绑定验证提供错误检测，尚无密码认证，恶意重新贴同一ID到不同参数的攻击不在本轮模型内。

原始训练checkpoint会话、发布会话、随机模型ID和推理会话保存在 summary，服务器loaded_private_files明确含自身 model-ID.json。正式公共标识不含权重/图/特征摘要。验证端可恢复发布权重计算期望值，但该恢复在服务器完成后，仅用于宽整数审计与对照，绝不重新拆分成在线参数输入。

## 同模型逐位对照

四条路径：全共享×布尔、private_decryption×布尔、全共享×FSS、private_decryption×FSS。全图推理，公开零偏置，隐藏层ReLU、输出层无ReLU。按以下六组输出测试份额：

1. XW0原始整个点积及一次f7精确截断。
2. P*T0原始点积、一次f7截断、范围验证后激活。
3. H*W1原始整个点积及一次f7截断。
4. P*T1原始点积和一次f7截断，直接作为输出分数。
5. 分数秘密范围检查后，同环公开乘32升到f12概率格式。
6. 同一已验收秘密近似概率协议。

全部135个环值在四路径之间和独立定点参考逐位一致，不使用容差。原始点积及部分和由验证端宽整数独立检查；线性层和共享聚合采用公开保守界+秘密操作数范围检查。HE的秘密输入T也范围检查，ct(P)的正确性与P范围由可信测试设置保证，未提供恶意密文认证或秘密图预处理。

## 新转换审阅与风险

依旧真实ct×本地全环份额、N逆元/Galois trace提取和打包，全系数独立均匀掩码；private_decryption直接用私有c0/c1和对方本地交叉私钥进行安全R_Q Beaver乘法，不发送求值密文。sk系数由key_context对应NTT表逆变换后截取first_context data模数，ct为二项非NTT表示；native校验规范RNS系数。CRT只对本方phase份额进行。最终BFV round使用两个秘密余数进位比较，随后两贡献合成、一次模型向下截断。每次ring材料ID连接前在持久表唯一预留，take先消费再打开，失败保留全部预留。

安全依据及允许泄漏沿用 he-conversion-security.md：可信非串谋且不看在线消息的离线方、两方半诚实、有效密钥和输入、标准Beaver/布尔安全组合；公开结构/顺序/范围有效整批标志、随机ID、公开近似参数。未公开符号/目标概率/完整phase；验证端才运行官方解码和噪声oracle。无主动安全、连接认证、OS隔离、常数时间保证；未证明任意规模HE噪声解析界。legacy_ciphertext必须显式选择，仅正确性诊断且安全阻塞，无自动回退。

## 十六节点与真实任务缺口

当前f12训练的公开界P<2、状态绝对值<8，点积容量D的保守界为 D*(2*4096)*(8*4096)=D*268435456。要求严格小于2^31，即D≤7；默认私有邻居访问使用公开capacity=N，因此16节点训练**预算不成立**，16给出4294967296，是有符号32位限值的2倍。即使把P界紧为1，16仍触及严格禁止的限值。本轮不擅自缩小状态界、不降低训练精度，也不将模环回绕后的范围检查当成溢出保护。

f7推理的对应界D*256*1024，16节点为4194304，可以落在32位内；但无法把它称作16节点完整训练闭环。拓展需要有依据的宽环乘积/截断或足够紧的逐点积界，且安全升环不能逐份普通扩环。HE packing容量N8192与这个训练累加限制不同，不能以packing容量承诺训练规模。

接入实际节点分类任务需：明确数据拥有者与标签授权；建立唯一输入schema/适配器（节点ID、无向非负加权边、特征矩阵、训练/验证/测试掩码、类别）；处理现实有向边及自环与当前拒绝规则的差异；支持特征/类别/隐藏维度变化并预检乘积界；去掉训练掩码个数必须2的幂的参考限制，使用可靠秘密除法；评估类别数增长导致概率量化为0；建立真实数据浮点/定点分离评测、数据许可和任务划分；选择稀疏秘密访问的可扩展协议。目前训练秘密索引是固定全扫描，P由验证端归一化提供，私有归一化和原辅助服务器协议未接入。没有真实数据适配器或数据集实验，不将小图成绩外推。

下一可实施单元应先建立真实数据的明文导入/范围预检与公开数据基线，确定输入约束及目标规模，再实现训练宽环或紧界方案；随后让数据拥有者生成实际共享输入，接入本链路。无需网页，也不需要恢复模型给拥有者。

### 真实数据规格的具体差距（只核查文档，不下载）

[PyG官方Planetoid 2.5.2规格](https://pytorch-geometric.readthedocs.io/en/2.5.2/generated/torch_geometric.datasets.Planetoid.html)列Cora为2708节点、1433维特征、7类别。这只是实际引用网络节点分类的接入差距示例，未安装PyG、下载数据或调用其GCN代码。当前f12首层公开界F*8192*16384<2^31要求F≤15，1433维无法直接接入；图容量界也不成立，必须先解决训练整数环/紧界和秘密稀疏访问。数据许可、具体导入文件/版本与标签划分仍需单独核实。

七分类还存在真实数值问题：公共参考夹具分数[-8,0,0,0,0,0,0]在当前f12近似产生目标指数单位2、分母24578，floor(2*4096/24578)=0。扩展log只覆盖正概率，不能因此声称消除多分类的概率下溢。本轮已保存该参考反例，没有使用公开目标概率或静默钳位修复训练。
