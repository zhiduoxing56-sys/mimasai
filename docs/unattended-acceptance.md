# 本轮真实数据与授权查询验收

## 实际任务、数据与模型

比赛设计稿1.3节计划Cora/CiteSeer/PubMed，3.1节为云端图节点分类，没有行业专用任务。本轮沿用原Cora论文引用节点分类，不下载GCN模型/训练框架，不换数据。原归档2708篇论文、5429引用记录、1433词特征、七类，SHA256与唯一配置一致。原归档没有明示再分发许可；数据不进Git或审阅包，不能称许可证已解决。

实际共享实验为64节点、487个子图有效词列、隐藏宽3、七类；108条原引用记录对应105个无向节点对，重复/反向权重相加；补一次单位自环后对称归一化。固定FIFO BFS（起点35，按数值节点号排序邻居）、诱导边、全零列删除、L2词特征归一化、ID哈希32/16/16划分均记录。节点和划分不按标签或测试效果选择。诱导重归一化改变传播语义，不等同完整图目标结果。两层GCN、公开零偏置、隐藏ReLU、输出无ReLU、全图传播后选择公开目标不变。

图与特征为公开基准；归一化在拥有者侧明文进行，随后共享。没有私人图归一化成果。在线服务器只读本方材料；本机同UID、应用层审计不是OS权限隔离，也不是主动安全或跨机认证。

## 真实训练与数值路线

本轮96次实际两进程共享更新逐项对齐既有定点参考，检查点1482个参数持续共享。每轮材料新生成；原state16第35轮拒绝、没有输出，历史批次再次启动返回BATCH_ALREADY_RESERVED。前34次成功更新保留，后62次用新材料和新政策继续，不恢复参数作为后续输入。

32位环、训练f12、推理f7、概率f12不变。旧通用前向界误用于后向已修复为backprop_state=1并在线验证。前向state24、score32使用唯一operand_bounds_real；非二次幂区间用完整有符号秘密比较精确检查[-24S,24S)，只打开整批有效位。P行L1上限21845、实际18615；X转置后向上限524287、实际39964，在线秘密验证相应条件后才做点积。界保证任意真实乘积及前缀和未超有符号环；当前环上的事后缩位检查不能替代此证明。依赖合法非负归一化P的HE公开上界，尚无加密P规范性验证。

任意正公开训练样本数的精确floor平均已实现：非二次幂秘密符号/无符号绝对值、条件修正、恢复除法、秘密恢复符号。小环穷举、32位MIN及随机、三样本真实训练均通过；64节点没有删除样本适配旧限制。新精确区间小环穷举与32位端点/失败烧毁通过；FSS位宽13/18各128输入与布尔ReLU逐位一致、区间外拒绝。索引训练3轮独立回归通过，Cora主链路仍为稠密共享P，不计大规模秘密索引完成。

96轮每轮计算的定点损失1.9267578125→0.488525390625；最终更新后同定点参考损失0.487548828125。初始训练准确率68.75%，末次84.375%；验证75%。对应浮点第96次更新后损失0.4867713742、训练84.375%、验证75%。160轮独立参考末损失浮点0.441452/定点0.439941；仍下降，不宣称96轮或160轮收敛。测试不参与选参。固定预算160的浮点与定点测试均87.5%，但训练多数类在测试也是87.5%（14/16）；没有七类泛化优越性结论。完整图此前1000轮浮点测试67.94%是历史明文证据，不记本轮新增完整图密态训练。

训练概率使用稳定秘密最大值、clip(-8)、T2近似和连续平方、秘密精确正除法；损失使用范围归约秘密对数，q=0拒绝、不钳位。梯度仍近似标准p−y，不是这些近似函数的精确导数。第96参考比较独立浮点/定点训练轨迹最大概率差0.040866，包含累计训练差；与同一个发布模型高精度softmax的近似误差另行报告，不能混为同一指标。

## 完整入口及角色

```sh
sh scripts/run_application.sh --nodes 64 --steps 96 --validate --faults
```

该入口从锁定数据及依赖开始，创建新会话、密钥和预处理，执行参考、真实训练、持续共享发布、查询及独立接收；--validate才由独立验证端恢复完整参数/中间状态，查询者没有这些权限。构建用系统前提及已有44份锁定公开归档，缺包时报具体名称；不是所有依赖从零离线重建。分开的prepare/train/publish/provision/request/offline/execute/receiver命令见application.md。账本永久留在state/mpc，失败未用材料也烧毁。

同一模型可以持续复用，查询必须新材料。权限是本机拥有者受控策略文件，不是密码认证。目标编号公开；服务器只向指定接收端交付授权目标的最终七类概率份额，不交付全节点矩阵、模型或中间状态。src.role_io把发布输入、请求输入、目标导出放在独立本角色进程；协调器不解析两方秘密。src.receiver仅读目标交付目录。页面延后：同UID环境没有可清楚证明的OS角色分隔，CLI实际运行真实后端。

## 安全论证边界

真实SEAL4.1.0、N8192、t=2^32、系数位[55,55,54,54]始终启用128位安全检查。交叉密钥分配、真实乘明文、逆N模Q投影/trace提取、打包、全8192系数CSPRNG掩码保持。private_decryption不向交叉私钥持有者传求值密文；R_Q Beaver秘密计算c1*sk、秘密CRT份额与两个进位实现精确BFV舍入，合并双方贡献后才精确f7截断。每层保留变换后及聚合后两次截断，不改模型语义。

半诚实、有效输入/密钥、可信非串谋离线、标准共享协议组合及合法输入加密的条件论证见he-conversion-security.md。测试只能证明测例输出和进程运行，不能替代安全证明。没有原论文低交互净化、通用提取/切换噪声解析上界、主动安全、计时侧信道保护、跨机认证或秘密目标查询；legacy_ciphertext继续安全阻塞，无自动回退。允许的批次有效/停止泄露保留，基准的完整效果恢复仅为独立测试端权限。
