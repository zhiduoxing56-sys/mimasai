# 真实数据入口与容量修复验收

本轮完成 Cora 数据入口、16节点96轮真实共享训练、持续共享发布、同模型受保护同态推理及秘密概率。32节点实际完成两轮共享更新；完整Cora仅完成浮点和定点参考，未完成完整图密态训练。数据和协议范围不能混同。

## 任务、数据与运行

比赛文档§1.3（印刷页6–7）列举Cora、CiteSeer、PubMed，§3.1（页12）规定云端图节点分类及图、特征、模型和查询隐私，未进一步指定行业业务。本轮使用其列举的Cora：论文节点、引用边、词特征、七类主题标签，属于作品工程验证基线。GCN、浮点训练、定点训练和共享后端为项目自有实现；下载的是数据及既有SEAL依赖，并非下载GCN模型。

入口：`sh scripts/run_real_data.sh`。默认96轮共享更新；可传整数限制复跑预算，例如 `sh scripts/run_real_data.sh 16`。完整图参考单独运行 `python3 verification/cora_full_reference.py --download`。固定划分、归一化记录及下载校验在src/data.py；具体规则见real-data.md。原始官方cora.tgz的SHA256为0d4ed463d1627bb7f3e8420effe8f5545fd492ae8f88dab44ce86cee7b26d7e8，168052字节；空缓存联网获取已实际验证。原README没有明确再分发许可，数据不进入Git或审阅包，不能标为许可问题已解决。

16/32节点采用按数值编号排序邻居的确定性BFS诱导子图，记录原始编号、词列及固定划分，重新归一化。它们不是原全图目标节点计算的等价替代。数据准备中的明文归一化仅为拥有者输入准备假设，不是私人图归一化协议。完整图浮点参考使用全部2708节点、1432个非零词列、隐藏维度3、七类输出，划分为256/512/1940，非标准Planetoid划分。

## 容量修复与失效证据

保留32位环、f12训练、f7推理、公开零偏置、隐藏ReLU和输出无ReLU、完整点积后一次向下截断。未逐项截断、关闭溢出检查或直接升环。

原d×最大操作数乘积界会拒绝某些实际安全矩阵。新路径先秘密验证操作数范围，再秘密计算行绝对值和，要求每行L1不超过floor((2^31−1)/另一操作数公开界)。另要求计算该L1自身的保守界不溢出。由三角不等式同时保护真实乘积与所有部分和；只公开整批合格标志，不公开行范数或位置。它仍可能保守拒绝抵消型安全输入。`verification/range_budget.py`已验证安全接受、保守拒绝及真实溢出拒绝，拒绝后无输出且材料不可重用。

16节点前90轮通过，原state8策略在第91轮拒绝：第一步输出层变换最大值32823/4096=8.0134277，超过公开8界；未发生整数溢出。参考160轮最大值10.1083984，因此唯一配置的状态预算改为16，分数仍16、权重仍4。更大状态预算反而使传播/梯度L1限额从65535收紧至32767，实际传播10426、转置特征9775仍通过。用新材料接续原90轮真实份额，91–96轮逐项通过。失败会话保留，预留的33584算术、2161820布尔、73861daBit全部作废；失败离线耗时未保存，不补造。

64节点转置词特征L1为39964，超过当前32767限额，故不强行运行。下一步可研究逐算子后向状态界以替代通用state16，但须秘密验证；分块累加不能用额外截断改变语义。更宽环需要可信跨环转换、重新验证概率/HE转换和材料预算，目前未实现。
