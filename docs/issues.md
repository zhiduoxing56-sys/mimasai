# 问题清单与待确认事项

以下问题按编码前是否会破坏安全、数值正确性或接口分类。阶段零分析记录保留；阶段一按用户明确选择落实参考语义和激活代数修正，原始材料与参与方信任假设未改。

| 打包尚无大批量噪声依据 | 实验独立 trace 实现有真实闭环，但非论文批量内核 | 明确 Galois 键来源、密钥生命周期和节点数上界；两标量测试不能证明全图深度可用 |
| 梯度与数值近似 | 比赛梯度使用标准 softmax 交叉熵梯度，但前向使用近似指数和倒数 | 确认采用近似标准梯度还是对近似函数求导；验证收敛和误差，不补实验数据 |

收敛式 4.14 的 `msb(α−|ΔL|)` 在有符号表示下为 1 通常表示差值大于阈值；3.2.2 表述为差值小于阈值才计停止窗口。必须定义标志极性、等于阈值的处理，以及窗口和最大迭代保护，不能仅照变量名写代码。

## 阶段一新增边界

明文参考权重摘要和测试份额文件不具备安全发布承诺；正式标识不能未经分析公开可猜测参数的摘要。两份共享测试由一个进程生成/刷新/恢复，未验证分布式随机性、认证或隔离。定点32/7仅用于前向，不外推为密态训练精度。当前k=10只来自测试模型明文观测，共享范围证明仍是阻塞项。收敛参考已落实≤、等号、连续窗口和上限；原式4.14差异及密态停止泄露仍需处理。

## 阶段二第一轮更新

已落实本机独立进程通信、可信离线生成、一次性保留/消费账本，以及与阶段一一致的32位/7位精确floor截断；不再把该局部精确路径列为“只有设计”。点积采用整体累加后一次截断，32位边界和小环穷举已通过。此构造使用ABY共享门/本地加法转换与daBit B2A，未声称SecGNN原代码或概率截断变得可直接复用。

影响安全或正确性：共享范围校验仍缺失；可信方不能读在线掩码或与服务器串谋；无主动作弊防护、OS隔离/跨机器认证、宿主回滚防护；训练环的数值与截断适配、跨域持续共享发布仍阻塞。state/mpc账本不得作为构建缓存清理或回滚。训练辅助方与离线方合并未定。

影响接口：会话/batch/attempt采用随机标识，正式共享原语不含明文参数摘要；握手只绑定公开调度。完整层/模型仍须绑定安全发布配置、权限与预处理分发。秘密访问、比较/选择密钥、安全概率及隐藏目标接口未实现。

## 阶段三第一轮问题更新

影响安全或正确性（新增硬阻塞）：全系数明文掩码不是密文视图净化；普通SEAL BFV的IND-CPA不保证持私钥接收者看不出本地操作数信息。36次检查显示c1未改变；完整simulatability/sanitization路径、误差界和参数未落实。不能临时增加“只看解码明文”的假设，不能用普通Enc(0)或实测噪声余量冒充证明。对应模块安全部署前必须解决。

已解决正确性与工程接口：真实同态多节点多列提取打包、交叉密钥分发、全部多项式系数掩码转换、合并两贡献后精确截断、两条激活及共享矩阵对照；随机标识和消费状态跨批次重用拒绝。参数/公钥摘要只绑定公开材料，未引入明文模型参数摘要。

继续阻塞：此前整数溢出保障、训练精度/算子、跨环保持共享发布、秘密索引、安全概率、隐藏查询、角色合并与部署认证/主动防护。接口完整性检查不等于恶意方密钥正确性证明。

后续优化：trace每节点13次Galois求值，评估键每组约20.5MB；三列每方约1.18MB转换载荷，测试trace文件IO影响耗时。可研究批量提取打包、列融合和净化路径，但不得改变两次截断位置、环尺度或完整系数掩码要求，不声称论文通信成本已经复现。
