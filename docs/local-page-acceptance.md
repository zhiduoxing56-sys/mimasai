## 部署后自主验收

```sh
python3 scripts/local_deployment.py audit
python3 scripts/local_deployment.py validate
```

先运行六个真实UID矩阵，再做一次真实页面API查询和一次输入准备故障；记录阶段、最终概率、实际耗时/发送通信量、独立批次/环材料/掩码ID、重复提交同一会话和清理后重执行拒绝。未连接则停止，不用假结果补齐。记录在`results/local-page`，能力令牌和浏览器cookie不进入公开记录/审阅包。不复核未改原语或重训。

新会话沿用磁盘准入/运行检查、完整进程组停止和永久作废。仅终止且停止确认后，由角色按预览核查、清理一次性材料；保留账本、材料标识、终止状态、模型、最终输出、报告及证据。分别记录内部/宿主余量、unlink分配块、最后链接分配块和可回收上界，不承诺VHD实际回收。不删除历史、不维护虚拟盘。

角色隔离仅是本机部署保障。管理员可访问材料；两方半诚实、可信非串谋离线方、可信状态存储和其他既有限制继续保留，不声称主动安全、跨机认证、完整Cora效果或浮点等价。
