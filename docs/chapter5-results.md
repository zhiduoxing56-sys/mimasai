# 第五章实验结果（事实口径）

本页从保留的真实记录生成。当前发布模型只覆盖 Cora 标签分层抽样后的 64 节点、551-6-7 两层网络；训练、验证、测试分别为 28、14、22 例。模型、种子和测试集未按本轮结果重选。

## 1. 密态训练

160 次真实密态更新：在线 5402.4 秒、14,764,569,920 字节；离线 10069.8 秒。首末密态损失 1.9436 → 0.2734。
已发布模型测试准确率 81.82%，宏 F1 82.01%；原选定 320 轮浮点参考测试准确率 81.82%。这两者训练轮数不同。
同图、同初始化、同 160 轮的已有浮点检查点事后只读评估：测试准确率 68.18%，宏 F1 64.05%；该事后检查未用于挑选模型。
在这 22 个测试节点上，一例分类变化对应约 4.55 个百分点。因此“下降不超过 1 个百分点”仅能表述为该小样本上观察到未下降，不能据此推断完整数据集或统计置信度。

## 2. 模型发布

3348 个参数从 12 位小数精度经秘密份额协议按有符号向下取整除以 32，刷新成 7 位模型；模型 ID `829a29a6913d505e7167f418a94674ee`。发布在线 1.674 秒、5,467,874 字节、228 轮；离线 3.634 秒。检查点绑定和四条推理轨迹逐位一致已由既有验收记录证明。
现有本机普通身份无权读取迁移后的双方模型份额，故本轮未取得经验权重转换最大误差；按实现规则理论误差小于 1/128。这个理论上界不能写成实际测量值。

同一批 32 个输入在两档均正确。10 位密钥更小、FSS 本体求值更快；其在线范围检查使本次总耗时与通信反而增加。密钥仅生成并写入离线私有文件，网络分发成本未实测。

## 5. 完整推理

既有实际发布模型、64 节点两层推理：测试准确率 81.82%；一次 HE + FSS 查询在线 35.761 秒、96,792,628 字节、1306 轮；离线 50.628 秒。分阶段耗时/通信保存在 `results/chapter5/summary.json` 和原始 `results/application/.../summary.json`。
测试集准确率由独立验证端核对全图输出；真实线上接收端只恢复固定授权目标的最终概率，不接收完整测试预测。
尚无同工作负载、相同设备及网络的外部安全图推理实现实测；20 倍时延与 400 倍通信目标均为“缺少可比基线，无法判断”，不可用文献数字或单层旧路径代替。
实际分阶段组件记录包括特征变换、图聚合、BFV 转换、范围检查、FSS 激活、截断和概率计算。`private_BFV_round` 是转换组件的内部部分，不能与父组件重复相加；见机器结果 `groups.5_inference.components`。既有真实页面截图：`results/local-page/connected-success.png`。
